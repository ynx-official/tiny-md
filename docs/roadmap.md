# 开发计划

## 方向

macOS 首发。Rust + GPUI + GPUI Component + Guise。
以 Guise MarkdownEditor 为底座，逐步实现 Typora 风格的编辑体验。
Markdown 原文始终是文档内容；应用层管理文件，适配层管理编辑器接入。

## 里程碑

| 阶段 | 范围 | 验收 |
|---|---|---|
| M0 技术兼容 | 锁定依赖，同窗口集成，主题与焦点 | 编译、启动与基础交互通过 |
| M1 编辑体验 | 中文输入、Unicode、选区、剪贴板、撤销 | 自动回归通过，真实系统输入法通过 |
| M2 应用结构 | app / editor-adapter / document，统一命令与事件 | 应用操作不意外重置编辑状态 |
| M3 写作闭环 | 基础 Markdown，新建、打开、保存、另存为、未保存提示 | 完整文章编辑后保存和重开正确 |
| M4 写作交互 | 排版打磨、大纲、查找替换、源码模式 | 模式切换保留位置与历史，查找跳转准确 |
| M5 复杂内容 | 图片、拖放、表格，随后公式、脚注、Mermaid | 交互操作正确写回 Markdown |
| M6 日常使用 | 自动保存、崩溃恢复、文件监听、设置、性能与发行 | 恢复可靠，性能达标，可安装使用 |

## 本轮实现

已落地的代码包括 M0 集成、M1 平台输入适配、M2 模块结构、M3 文件操作，
以及 M4 中的大纲、源码模式与主题切换。

代码块已增加卡片样式、语言标识、复制反馈，并补全 Guise 支持的常用语言高亮映射。
M5 中的 Mermaid 流程图已接入原生预览、源码编辑、主题切换和错误回退。
表格已支持网格直接编辑、列对齐、换行、单元格导航、行列增删及末行新增；
使用用户完整文档的 24 个表格作为回归样例。

界面已按用户提供的 Typora 参考改为简洁文档窗口，主要操作移入 macOS 原生菜单。
已增加独立窗口、会话内最近文件、查找替换、段落和格式命令、只读 / 专注 / 打字机模式、缩放。
根据追加参考图，工具栏改为底部悬浮的排版操作栏，侧栏区分文档列表与大纲。
文档列表支持当前文件夹 Markdown 文件、摘要、选中状态、刷新和安全切换；
图片按钮目前插入 Markdown 图片链接，内嵌预览仍在后续任务中。
M4 中的查找替换已落地，M6 的设置持久化和性能测量仍待完成。

是否通过阶段验收以 [验证记录](verification.md) 为准；存在代码不等于验收完成。

## 下一批任务

1. 完成真实 macOS 拼音验收，必要时修复组合期间的光标、布局与候选框位置。
2. 对 10 KB / 100 KB / 1 MB 文档记录输入和滚动性能，按测量优化。
3. 扩展跨行格式操作，增加标签页与文件树，并完善 Markdown 语法兼容性样例。
4. 实现图片与拖放，补齐表格拖动列宽和批量粘贴，增加导出与打印。
5. 完成自动保存、崩溃恢复、设置持久化与发行流程。
