## 版本概述

首次提供 Tiny MD 原生 Markdown 写作应用的 macOS Apple Silicon 和 Windows x64 安装包。

## 用户能力

- 原生写作窗口、Markdown 编辑与基本文件操作。
- macOS 使用 DMG 拖入 Applications；Windows 使用当前用户安装程序，提供快捷方式和卸载入口。
