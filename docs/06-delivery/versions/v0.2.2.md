## 版本概述

修复 Windows 在线更新安装失败后重新打开旧版的问题，并让新安装包兼容旧版更新助手。
同时改善连续输入时的光标同步、打开笔记时的空白窗口复用和侧栏滚动 / 调宽交互。

## Windows 在线更新

- 修复安装器无法接受扩展路径而安装失败的问题，保留原安装目录和当前用户权限。
- 新安装包兼容 v0.2.0 / v0.2.1 的旧助手，无需先手动替换助手即可升级。
- 新助手自动安装时显示进度，失败时弹出提示并提供诊断日志位置，避免把重新打开旧版误认为更新成功。
- 保留安装前的未保存检查、下载完整性校验与失败恢复；其他实例仍在运行时停止安装，不强制关闭它们。

## 写作与窗口改进

- 修复快速输入中文、英文、emoji，段落换行和自动滚动时光标显示与实际插入位置错位的问题。
- 打开笔记时复用没有待保存内容的空白未命名窗口，避免留下多余空窗口；已有笔记与草稿继续保留。
- 侧栏调宽改用细虚线提示，滚动条与调宽入口分开；长大纲显示可拖动的滚动条。

## 配置与数据兼容性

Markdown 文件格式与更新设置没有迁移，不上传文档或编辑内容。
Windows 继续按当前用户安装，保留现有文件关联设置和右键入口；不强制覆盖系统默认打开方式。
构建沿用最高优化等级、全量 LTO、单一代码生成单元及 Windows 静态 MSVC 运行库。

## 升级说明

v0.2.0 / v0.2.1 用户可在“帮助 → 检查更新”下载本版本，再选择“安装并重启”。
先保存所有需要保留的内容，并关闭使用同一安装目录的其他 Tiny MD 实例。

旧版复制的是旧助手，首次升级仍可能隐藏进度窗口；新安装包会处理其路径参数，
安装结束后请在“关于”确认版本为 v0.2.2。进度与失败弹窗的助手改进会用于之后的升级。
若首次升级仍失败，可从本版本 Release 手动运行 Windows setup 安装。
v0.1.0 用户需要手动安装一次；便携 Windows 使用 ZIP，macOS Apple Silicon 使用 DMG 或便携 ZIP。
安装重启不会恢复未命名文档、光标或撤销历史，请先保存需要保留的笔记。

## 已知限制

- Windows 原生安装进度 / 失败弹窗、真实高速键盘输入和系统输入法仍需人工验收；开发阶段隔离回归不等同于实际用户目录的升级验收。
- macOS 仅支持 Apple Silicon，仍为 ad-hoc 签名，尚无 Apple 开发者签名与公证。
- 尚无自动保存或崩溃恢复；图片内嵌、导出 / 打印、标签页及 Linux 不在本版本范围。
