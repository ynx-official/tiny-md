## 版本概述

加快多流程图文档的生成与重开，稳定加载期间的阅读位置，补齐正常 Mermaid 流程图的解析兼容性。

## 流程图加载

- 流程图默认使用原生 ELK 布局，复用系统字体数据，缩短复杂图首次生成的等待；Windows 中文图使用微软雅黑。
- 布局、正文预览和高清查看共用最多 5 个后台计算名额，正文结果按文档顺序显示。
- 内存缓存复用同次运行中已生成的图，切换或重开文档无需重复渲染未变化的内容；源码或主题变化后更新对应图形。
- 加载时用骨架预留空间并保持阅读位置，拖动滚动条期间固定图形高度，减少加载造成的页面跳动。

## 滚动与兼容修复

- 长文档在窗口最右侧显示常驻窄滚动条，支持拖动和点击轨道定位。
- 修复大写 `END` 节点被误判为子图结束，以及带标签链式连接遗漏后续连线的问题，保留原节点、标签与全部分支。
- 扩大有界正文图形缓存预算，使完整参考文档的 35 张有效图形能在同次运行中复用。
- 优化开发构建的第三方依赖，改善使用 `cargo run` 时的流程图生成体验。

## 验证结果

- 用户于 2026-10-14 明确要求正式发版并跳过测试，授权准备发布资料、提交和推送源码及创建正式标签。
- 工作流仅对 `v0.2.9` 跳过 Rust / Python、Windows 安装卸载及隔离更新助手测试；保留版本资料、格式 / Clippy、双平台构建、包格式 / 签名与附件完整性核对。
- 开发阶段 209 项 Rust 测试、17 项发布工具测试、深浅主题 70 张位图对照及完整文档缓存回归的记录见[解析兼容性](../../04-quality/mermaid-parser-compatibility.md)，不作为版本升级后重跑测试的证据。
- 开发阶段参考文档的 35 张图全部生成，5 个 CPU 工作者墙钟约 0.621 秒；计时不含原生窗口排版与 GPU 显示，未与 Typora 做同机原生计时对照。
- 本机版本资料、四个锁文件包版本、离线 Cargo metadata、格式、diff 及 Windows MSVC x64 all-targets Clippy 检查通过，未运行测试；修正后的两处 RGBA 分组检查编译通过。
- 双平台流水线与公开附件核对结果将在实际执行后记录；尚未进行 macOS 原生界面、系统输入法或真实安装升级验收。
