# Tiny MD v0.2.4

## 版本概述

修复任务复选框点击后跳回文首的问题，为正文可交互内容补齐手形光标，
并改善表格和换行链接的点击范围，保持阅读与编辑过程连贯。

## 复选框与阅读位置

- 勾选或取消任务复选框时保持当前阅读位置，避免被文首的文本光标拉回顶部。
- 保留已有选区与方向，任务修改继续支持保存、撤销与重做。
- 普通模式与打字机模式均采用原位切换；只读模式的复选框不修改文档。

## 链接与交互提示

- 超链接、可编辑复选框与可点击展开源码的流程图入口显示手形光标。
- 链接点击范围与实际排版文字对齐，表格内链接、中文 / 英文混排和换行后的各行均可点击。
- Windows 使用 Ctrl+点击打开链接，macOS 使用 Cmd+点击；可编辑模式普通点击继续定位光标。
- 只读模式普通点击即可激活链接；正文普通文字、链接周围空白及源码模式不激活预览链接。

## 兼容性与升级

Markdown 文件与本机配置没有迁移，延续 v0.2.3 的主题、更新检查与可选后台自动下载设置。
Windows 安装版使用 setup EXE，便携版使用 ZIP；macOS Apple Silicon 使用 DMG 或便携 ZIP。
在“帮助 → 检查更新”下载并校验后，选择“安装并重启”；安装前处理未保存笔记。
v0.1.0 没有在线更新入口，需要手动安装一次。

## 已知限制

- 本次正式发版按用户要求跳过测试；原生系统的鼠标光标外观、真实鼠标交互与本版本安装升级仍需实机确认。
- macOS 仅支持 Apple Silicon，使用 ad-hoc 签名，尚无 Apple 开发者签名与公证。
- 尚无自动保存或崩溃恢复；图片内嵌、导出 / 打印、标签页及 Linux 不在本版本范围。
