## 版本概述

本版本新增应用内在线更新与外部文件同步，改善 Windows 写作布局、长文档编辑和 Mermaid 高清查看。
从 v0.1.0 升级后，可在帮助菜单检查后续稳定版本，查看变更日志并在保护未保存文档后安装更新。

## 在线更新与发布日志

- 检查更新优先使用发布清单，GitHub API 和发布页面依次兜底，按当前平台和安装方式选择更新包。
- 更新窗口显示当前版本、新版本日志和下载进度，支持取消、重试与用户确认后的安装重启。
- 下载采用流式写盘、大小限制、SHA-256 校验和安全解包；安装助手启动前再次核验归档与版本。
- 自动检查可选择启动时、按间隔或关闭，偏好保存到本机；自动检查不会自行下载或安装。
- 安装前逐窗口处理未保存文档，取消或保存失败时保留窗口。开发构建不能安装更新。
- 版本详情作为日志唯一正文来源，GitHub Release 和应用更新窗口使用同一发布说明。
- 发布资料校验要求标签、Cargo / 锁文件版本、日期和日志索引一致，完整附件先上传到草稿再公开。

## 外部文件同步

- 文件事件触发同步，定期字节核对兜底；干净文档自动读入其他应用保存的内容。
- 不重叠的本地与磁盘修改按行合并，保留本地未保存状态与编辑器撤销历史。
- 重叠冲突不覆盖双方内容，提供另存本地副本、同步磁盘版本或取消。
- 保存前再次核对磁盘，保留 UTF-8 BOM 和统一 CRLF；不可读、删除或无效 UTF-8 时保留本地编辑。

## 编辑与 Windows 界面改进

- 长文档复用 Markdown 结构、排版和可见行缓存，减少滚动与普通输入时的重复工作。
- Windows 采用左侧应用标题、紧凑菜单与底栏，默认空白文档，提供 Alt 菜单访问键与 F10 入口。
- 改进 Windows 系统字体、只读 / 源码状态提示和未保存标记；正文光标保持细线与闪烁反馈。

## Mermaid 高清查看

- 打开文档后后台准备流程图预览；正文按显示尺寸生成位图，调整尺寸时释放旧资源。
- “查看”打开独立窗口，支持适合窗口、100%、滚轮缩放和左键拖动。
- 独立查看使用一次生成的高清整图，缩放与拖动不反复解码，关闭窗口时释放位图与 GPU 资源。
- 修复查看窗口关闭和放大拖动中的重复加载；预览与查看均为只读快照，不改变 Markdown 内容。

## 配置与数据兼容性

Markdown 文件格式没有迁移；新增本机更新设置，不上传文档、路径或编辑内容。
Windows 默认保存在 `%LOCALAPPDATA%/Tiny MD/update-settings.json`，
macOS 为 `~/Library/Application Support/Tiny MD/update-settings.json`。
旧版不读取此设置，可通过手动覆盖安装回退；回退前保存所有文档。

## 升级说明

v0.1.0 没有在线更新入口，必须先从本版本 Release 手动安装一次。
Windows 安装版使用 setup EXE，便携版解压对应 ZIP；macOS Apple Silicon 使用 DMG 拖入 Applications。
之后 Windows 安装版通过 EXE 更新，Windows 便携版与 macOS `.app` 使用对应 ZIP 在线更新。
安装前保存或明确放弃所有未保存内容；重启不会恢复未命名文档、光标或撤销历史。

## 已知限制

- 本次按用户要求跳过测试，双平台构建与产物校验不能替代原生交互和安装重启验收。
- macOS 仅支持 Apple Silicon，当前仍为 ad-hoc 签名，尚无 Apple 开发者签名与公证。
- 外部合并按行处理，同一行不同位置的修改仍可能形成冲突；尚无自动保存或崩溃恢复。
- Mermaid 查看是固定高分辨率位图，超出其像素规格会变模糊；超大图按资源上限缩小。
- 图片内嵌、导出 / 打印、标签页及 Linux 仍不在本版本范围。
