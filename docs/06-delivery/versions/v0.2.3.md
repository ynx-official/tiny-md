## 版本概述

新增分类偏好设置，集中管理主题、更新频率与后台下载。更新页重新设计，
版本信息与主要操作更集中，更新日志留出更清晰的阅读空间。

## 偏好设置

- “文件”菜单新增“偏好设置…”，Windows 使用 Ctrl+,，macOS 使用 ⌘,。
- 左侧分为“外观”和“更新”，重复打开复用同一个设置窗口。
- 浅色 / 深色主题立即应用到文档和工具窗口，下次启动保留；已打开的流程图窗口也跟随主题。
- 更新检查可选启动时、按间隔或关闭；检查间隔支持 1–8760 小时。
- 设置保存失败时提示原因，保留原来的有效设置，不影响笔记内容与未保存草稿。

## 在线更新与后台下载

- 更新页采用简洁版本区，检查、下载、取消和安装操作位于顶部，底部保留更新设置、发布页面与关闭。
- 去掉日志标签整圈黑框与厚重灰色页脚，增加正文留白和行距，Markdown 日志可独立滚动、选择与复制。
- 未发现新版时显示当前版本日志；有新版后提供新版本 / 当前版本切换，并标明正在阅读的版本。
- “偏好设置 → 更新”新增“后台自动下载”，默认关闭。开启后发现新版会后台下载，完整性与解包校验成功后再弹出更新页。
- 手动检查同样遵循下载偏好；可关闭更新页继续写作。关闭自动下载选项会取消自动任务，手动下载继续。
- 下载失败、取消或校验未通过时不自动弹窗；等待安装期间避免重复检查和重复下载。
- 安装仍须用户确认，并逐窗口处理未保存文档。开发构建保持手动检查和下载，禁止安装更新。

## 配置与数据兼容性

Markdown 文件格式没有迁移，不上传笔记内容。
主题保存于本机 `preferences.json`，更新设置沿用 `update-settings.json`。
旧更新配置无需手动迁移，保留原检查模式、间隔与最后检查时间；缺少后台下载字段时按关闭处理。
Windows 保留现有右键入口和文件关联选择；构建继续使用最高优化等级、全量 LTO、单一代码生成单元和静态 MSVC 运行库。

## 升级说明

在“帮助 → 检查更新”下载本版本，校验完成后选择“安装并重启”。
需要保留的未命名笔记应先保存，并关闭使用同一安装目录的其他实例。
升级后从“文件 → 偏好设置 → 更新”开启后台自动下载，该设置用于之后发现的新版本。

Windows 安装版使用 setup EXE，便携版使用 ZIP；macOS Apple Silicon 使用 DMG 或便携 ZIP。
v0.1.0 没有在线更新入口，需要手动安装一次。安装重启不会恢复未命名文档、光标或撤销历史。

## 已知限制

- 本次正式发版按用户要求跳过测试；开发阶段已有回归记录，原生后台下载弹窗与跨平台真实安装升级仍需实机确认。
- macOS 仅支持 Apple Silicon，使用 ad-hoc 签名，尚无 Apple 开发者签名与公证。
- 尚无自动保存或崩溃恢复；图片内嵌、导出 / 打印、标签页及 Linux 不在本版本范围。
