## 版本概述

补齐 macOS 排版模式的段落空行间距修复，让 Windows 与 macOS 共用相同的分隔规则。

## 段落空行间距

- macOS 单个段落分隔空行的显示高度减半；默认 16 px 字号下，相邻单行段落的间隔由 52 px 收紧为 39 px，与 Windows 一致。
- 两端保留原文、连续空行、文首文末空行及代码内部空行的原有规则；源码模式、标题自身留白和窗口布局继续沿用各自的设置。

## 验证结果

- 用户于 2026-10-13 明确要求正式发版并跳过测试，授权准备发布资料、提交和推送源码及创建正式标签。
- 工作流仅对 `v0.2.7` 跳过 Rust / Python、Windows 安装卸载及隔离更新助手测试；保留版本资料、格式 / Clippy、双平台构建、包格式 / 签名与附件完整性核对。
- 开发阶段 Review、先失败后通过的双平台应用配置回归及 170 项工作区测试记录见[段落空行间距](../../04-quality/paragraph-spacing.md)，不作为本次版本升级后重跑测试的证据。
