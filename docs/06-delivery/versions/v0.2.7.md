## 版本概述

补齐 macOS 排版模式的段落空行间距修复，让 Windows 与 macOS 共用相同的分隔规则。

## 段落空行间距

- macOS 单个段落分隔空行的显示高度减半；默认 16 px 字号下，相邻单行段落的间隔由 52 px 收紧为 39 px，与 Windows 一致。
- 两端保留原文、连续空行、文首文末空行及代码内部空行的原有规则；源码模式、标题自身留白和窗口布局继续沿用各自的设置。
