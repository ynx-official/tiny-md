## 版本概述

改进 Mermaid 流程图的分支布局、连线路径和中文决策标签排版，让流程更易阅读且减少节点留白。

## Mermaid 流程图

- 优化自上而下流程图中同级分支的阅读顺序，共同入口的退回线优先从右侧绕行。
- 未分组流程图使用可斜向连接的折线，让分叉和汇合更直接，分支标签靠近连线。
- 共享入口的退回线在路径安全时通过两个折点从入口右侧不同位置接回；若新路径会穿过节点或其他图形元素，则保留原有布局路径。
- 长中文决策标签按自然断点折为两行，避免标点落在行首；作者指定的换行继续保留。

实现与交互边界见[ELK 流程图布局](../../03-architecture/flowchart-elk-layout.md)，回归样例和验证记录见[流程图阅读顺序验证](../../04-quality/flowchart-reading-order.md)。

- Windows 完整检查通过：19 项 Python 发布工具测试、352 项 Rust 测试通过；2 项原有手工性能测试和 1 项 doctest 忽略；rustfmt 与 workspace all-target Clippy（`-D warnings`）通过。
