## 版本概述

新增正文排版偏好，可调节正文最大宽度、字体、字号、行高和段落间距，并同步应用于已打开的文档窗口。

## 正文排版

- 默认正文宽度为 1140 px，可设置 480–2000 px；窗口较窄时正文自动收窄。
- 可搜索并选择本机字体，调整 12–30 px 字号、1.2–2.4 倍行高及 0.25–2 行段落间距。
- 设置保存在本地偏好中，支持跨重启保存、即时应用到所有文档窗口和恢复默认。
- 校验输入并保留旧设置；排版调整不修改文档源码、撤销栈和未保存状态。
- Windows 与 macOS 共用排版参数，代码和源码仍使用等宽字体。

默认值、范围、布局及兼容边界见[正文排版偏好](../../02-design/typography.md)。
