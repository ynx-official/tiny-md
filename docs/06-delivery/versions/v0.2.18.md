## 版本概述

更新设置支持管理多条自定义下载线路；Markdown 表格工具栏改为悬浮显示，不再占用固定正文空间。

## 更新线路

- 支持逐条新增和移除自定义 HTTPS 线路，并可单独选择其中一条。
- 自动模式会检测全部已保存线路；删除当前指定线路后回到自动择优。
- 旧版单地址设置会迁移到线路列表，保存时规范化并去重。
- 每轮线路并发探测最多 4 条；已有线路状态、签名校验和下载安全边界保持一致。

## Markdown 表格工具栏

- 工具栏悬浮在表格附近，不再保留固定高度占位，不影响正文排版。
- 定位表格时显示工具栏并避让前文与表头；进入或离开表格不改变文档行位置。
- 保留列对齐、行列增删与移动、复制、格式化、删除整表及撤销等已有操作。

具体行为与边界见[更新线路设计](../../02-design/update-routes.md)、[更新线路验证](../../04-quality/update-routes.md)及[表格工具栏验证](../../04-quality/markdown-table-controls.md)。

## 验证结果

- Windows 完整检查通过：19 项 Python 发布工具测试、348 项 Rust 测试通过；2 项原有手工性能测试和 1 项 doctest 忽略；rustfmt 与 workspace all-target Clippy（`-D warnings`）通过。
- `./scripts/bundle-windows.ps1 -Portable` 构建成功；核验 Windows x64 GUI 可执行文件、9 个嵌入图标帧，`--version` 输出 `Tiny MD 0.2.18`。
- 使用受控私钥对现有公开更新清单做签名预检，并用客户端内置公钥验签通过；签名密钥与发布公钥匹配。
- 待正式流水线完成 macOS arm64 / Windows x64 构建、包验证和更新清单签名。
