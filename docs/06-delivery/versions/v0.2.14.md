## 版本概述

扩展 Markdown 文档中的 HTML 原生预览，改善常见混排、图片徽章、标题、表格、折叠和功能标记显示。

## HTML 混排预览

- 支持常见文字标签、完整 HTML 实体、有限文字样式、对齐和链接；HTML 图片可设宽高并复用现有图片加载边界。
- 支持 `h1`–`h6`，复用对应 Markdown 标题字号与留白，并保留对齐和嵌套文字样式。
- 支持 `details` / `summary` 折叠内容和 HTML 表格，包括表头、标题、链接、图片及单元格合并。
- 图片徽章组横向排列，窄窗口自动换行，保留图片链接及容器对齐。
- 独立 `<br/>` 显示为可定位的淡灰色原文标记；HTML 注释显示为金色等宽提示，行内换行仍按实际语法处理。
- 预览、点击编辑和源码模式保留原始 HTML；保存不格式化或重写源码，并保持撤销及中文组合输入边界。

## 安全与兼容边界

使用有限 HTML 原生映射，不执行脚本、事件属性、iframe、外部样式表或任意 CSS；不支持的标签保留为源码。
完整规则、限制与原生验收边界见 [HTML 混排兼容](../../04-quality/html-compatibility.md)。

## 内存优化

普通 SVG 图片共用系统字体索引，并按需读取字体；流程图字体缓存限制保留容量，降低含 SVG 徽章文档的首次打开内存。
