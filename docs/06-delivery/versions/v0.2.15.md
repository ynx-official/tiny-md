## 版本概述

新增 Markdown 表格编辑操作、系统主题跟随和持久化最近文件记录，改善长文档编辑和常用文件访问。

## Markdown 表格操作

- 提供列对齐、行列插入 / 移动 / 删除、复制表格、格式化源码和整表删除工具。
- 尺寸面板支持网格选择及行列数输入；缩小时在移除有内容单元格前确认，修改可一次撤销。
- 表格结构编辑保留超出表头列数的源码内容，跨出表格的选区不提供表格操作。
- 表头和隔行采用实色底纹，深色主题同步适配，当前编辑行高亮优先。

详细菜单、焦点、源码、撤销和平台验收边界见 [Markdown 表格快捷操作](../../04-quality/markdown-table-controls.md)。

## 夜间模式与最近文件

- 外观设置提供黑夜、白天、跟随电脑三档模式，默认跟随系统；手动选择跨重启保存，主题菜单同步切换。
- 最近文件持久记录最多 20 项，重复文件移至顶部；另存为、重命名和删除同步更新记录，并支持清除。
- 最近文件菜单展示长路径时省略中间部分，不可用路径保留至用户打开；文件失败不会替换当前文档。

存储位置、异常处理和窗口边界见 [最近文件记录](../../02-design/recent-files.md)。
