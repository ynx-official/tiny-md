## 版本概述

改进大纲章节跳转和侧栏文档定位，便于在长文档中继续阅读并快速找到当前文件。

## 大纲章节定位

- 点击大纲章节后，将章节起点尽量对齐正文视口顶部；排版、源码与打字机模式采用统一规则。
- 文末章节遵循实际滚动范围，不额外增加空白；普通输入继续使用原有光标滚动行为。

## 侧栏文档定位

- 文档列表和文档树在打开 / 切换文档、显示侧栏模式、重开侧栏及目录刷新后定位当前文档。
- 文档树默认仅展开当前文档所在目录的祖先链，收起其他目录；未命名文档选中侧栏顶部项目。
- 普通重绘和调宽保留用户手动滚动与目录展开状态。

## 验证结果

- 用户于 2026-10-14 明确要求正式发版并跳过测试。
- 发布测试、Windows 安装卸载及更新助手测试均跳过；版本资料、格式 / Clippy、双平台构建、打包及附件完整性核对由正式流水线执行，结果待发布后补记。
- 本机 `python -B scripts/release_notes.py --check-current`、离线 Cargo metadata、`cargo fmt --all -- --check`、`git diff --check` 与 Windows x64 workspace all-targets Clippy（`-D warnings`）通过；未运行测试。
