## 版本概述

本版本改善多篇笔记的打开与管理：每篇笔记使用独立窗口，支持批量打开和文件拖放，保留原窗口的内容与未保存修改。
Windows 安装增加右键和默认应用选择入口，同时改善侧栏调宽、应用图标、标题居中及更新日志阅读。

## 独立文档窗口与文件拖放

- 文件菜单、最近文件、侧栏列表 / 文档树及右键打开均在独立窗口显示笔记，保留原窗口的正文、未保存修改和撤销历史。
- 文件对话框允许一次选择多篇笔记；批量打开中某个文件失败时，其他有效文件仍可打开。
- 可一次拖入一篇或多篇 `.md`、`.markdown`、`.mdown` 文件，扩展名不区分大小写；包含其他扩展名的拖放不打开。
- 各窗口独立保存与关闭；重新加载仍更新当前窗口，并检查未保存内容。

## Windows 文件集成

- 安装后为 `.md` 和 `.markdown` 注册“通过 Tiny MD 打开”右键入口，以及系统“打开方式”中的 Tiny MD。
- 安装新增两个默认打开勾选项，首次安装默认不勾选；选中后引导到 Windows 默认应用设置，由用户在系统中确认。
- Windows 11 的传统右键入口位于“显示更多选项”；Windows 10 使用默认应用设置总页。
- 静默更新保留现有默认应用，不打开设置页；重装更新同一入口，卸载清理 Tiny MD 专属注册。

## 写作界面与日志阅读

- 拖动侧边栏右侧分隔线可连续调宽，文档列表、文档树和大纲共享本窗口的调整结果，隐藏再打开时保留宽度。
- Windows 顶部文档文件名按整个窗口居中；长文件名截断时仍保留未保存标记。
- 更新窗口将当前版本与新版本日志按 Markdown 排版，支持标题、列表、强调、链接、引用、代码和表格，并允许选择和复制。
- 收紧 Windows 图标留白并补齐常用 DPI 尺寸；macOS 改用去掉自带外框的独立满画布图标素材。

## 配置与数据兼容性

Markdown 文件格式与更新设置没有迁移，不上传文档或编辑内容。
侧栏宽度只保留在本窗口会话中。Windows 安装注册当前用户的应用入口，不强制覆盖系统默认打开方式。
release 构建采用最高优化等级、全量 LTO 与单一代码生成单元；目标 CPU 兼容范围保持原有设置，性能与包体收益尚未测量。

## 升级说明

v0.2.0 用户可在“帮助 → 检查更新”下载本版本，确认安装前先处理所有窗口的未保存内容。
v0.1.0 用户需要从 Release 手动安装。Windows 安装版使用 setup EXE，便携版使用 ZIP；
macOS Apple Silicon 使用 DMG 或便携 ZIP。Windows 文件集成仅由安装版注册。
安装重启不会恢复未命名文档、光标或撤销历史，请先保存需要保留的笔记。

## 已知限制

- 本次按用户要求跳过 Rust / Python 测试、Windows 安装卸载和更新助手测试；构建与产物校验不能替代原生交互及安装重启验收。
- Windows 资源管理器拖放、默认应用选择以及 macOS 原生拖放 / Dock 图标仍需实机验收；macOS 12–15 的满画布图标可能保留方形外形。
- macOS 仅支持 Apple Silicon，仍为 ad-hoc 签名，尚无 Apple 开发者签名与公证。
- 尚无自动保存或崩溃恢复；图片内嵌、导出 / 打印、标签页及 Linux 不在本版本范围。
