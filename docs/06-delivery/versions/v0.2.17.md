## 版本概述

更新页增加网络线路选择和测速；新更新清单使用 Ed25519 发布者签名，保留旧清单兼容和安装包完整性校验。

## 更新线路

- 自动择优并发检测 GitHub、gh-proxy.com、ghfast.top 与已保存的自定义线路，展示线路状态、耗时和可用版本。
- 支持仅 GitHub、指定线路和自定义 HTTPS 线路；网络传输错误时仅在符合条件的线路间有限重试。
- 检查更新前重新探测并锁定本轮版本与附件；测速操作不启动下载或改变检查历史。
- 请求和设置保护现有 TLS、附件来源、大小、SHA-256、取消及手动确认安装规则。

## 更新清单签名

- 新清单附件带 Ed25519 发布者签名，客户端使用内置公钥验证原始清单字节和 Release Notes 哈希。
- 历史无签名清单仍要求 GitHub 直连核验；无效签名不会降级为无签名清单。
- 正式发布生成签名清单、签名附件及覆盖全部产物的 SHA256SUMS。

具体线路、兼容和信任边界见[更新线路与测速](../../02-design/update-routes.md)及[发布签名说明](../../05-operations/update-signing.md)。

## 验证结果

- Windows 检查脚本通过：19 项 Python 发布工具测试、340 项 Rust 测试通过；2 项原有手动性能测试和 1 项 doctest 忽略；格式和 workspace all-targets Clippy 通过。
- 本地使用受控私钥对公开清单签名，并使用客户端内置公钥独立验签通过；私钥未写入工作区。
- 本机 Windows x64 Release 构建成功：`cargo build --locked --release -p tiny-md --target x86_64-pc-windows-msvc`；PE32+ / GUI 子系统、9 个嵌入图标帧核验通过，`--version` 输出 `Tiny MD 0.2.17`。
- 正式流水线双平台构建、打包和签名附件核验待完成。
