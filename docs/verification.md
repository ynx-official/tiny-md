## 手工输入法验收步骤

1. 使用 macOS 简体拼音，在正文中输入“你好，世界”，翻页选词并确认。
2. 输入拼音后按 Escape，确认没有留下拼音或破坏已有正文。
3. 在标题、粗体、链接、列表和自动换行处重复上述操作。
4. 在 emoji 后选择一段文字，使用输入法替换；检查候选框跟随光标。
5. 撤销一次应恢复提交前内容，不应逐次出现拼音候选。
6. 连续输入英文后撤销，检查普通输入仍合并为合理的历史步骤。
7. 切换源码模式再返回，检查光标、选区与撤销历史保持有效。
