## 版本概述

在 Markdown 正文中预览本地和远程图片，同时保留原文编辑与文档状态。

## 图片预览

- 支持相对于 Markdown 文件的本地路径，以及 HTTP / HTTPS 图片；相对路径跟随文件位置。
- 支持在正文、表格和混合文字段落中按原宽高比显示图片；小图不放大。
- 可切换编辑图片所在的 Markdown 源码，图片加载不修改原文或撤销历史。
- 加载失败时显示错误与重试入口；资源随地址、文档或窗口生命周期释放，不写入磁盘缓存。

## 未发布原因

- 正式流水线 [v0.2.12](https://github.com/ynx-official/tiny-md/actions/runs/38852304024) 的版本资料校验通过；macOS arm64 与 Windows x64 Clippy 在 `markdown_images.rs` 两处固定 4 字节分块上失败。
- Rust 1.99.0 新增 `chunks_exact_to_as_chunks` lint，拒绝 `chunks_exact_mut(4)`；没有进入双平台 Release 构建与附件生成，未创建公开 Release。
- 本机与开发阶段使用的 Clippy 曾通过该代码；CI 使用的较新 Clippy 版本暴露兼容问题。测试按用户要求跳过。
- 原标签 `v0.2.12` 保留不移动，改用独立补丁版本 `v0.2.13` 发布。
