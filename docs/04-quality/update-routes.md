## 2026-10-30：多条自定义线路管理

### 变更与失败回归

用户要求自定义线路可以逐条新增、移除。先运行失败回归，确认原实现只读取单条地址、没有新增入口，且多线路探测仅返回原有三条内置线路；再实现集合保存、旧配置迁移和交互。

| 边界 | 本次验证 |
|---|---|
| 配置兼容 | 旧单条地址在自动与指定模式下均迁入列表，保留检查周期和历史；多条地址重启后保留 |
| 新增与校验 | 连续新增保留已有地址，自动模式不变；拒绝规范化后重复的地址、内置线路地址及非 HTTPS 地址 |
| 移除 | 只移除对应地址；删除非当前线路保留当前选择，删除当前指定线路切回自动；重载不会恢复已删除线路 |
| 保存和状态 | 保存失败不修改内存配置及原文件；更新中不能修改；移除后旧测速结果与下载计划失效 |

| GPUI 交互 | 点击新增、按钮 / 回车连续添加、下拉选用、逐条点击移除及列表持久化通过窗口测试 |
| 布局 | 默认尺寸控件存在；640 × 430 深浅色主题下，长地址不挤出移除按钮，检查更新按钮可滚动访问 |
