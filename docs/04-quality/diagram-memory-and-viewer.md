## 实现

- Mermaid 解析与布局结果生成具有逻辑尺寸的 SVG；不再预先放大宽高 3 倍。
- 正文按当前显示宽高乘窗口系统缩放决定像素尺寸，窗口宽度或图形缩放改变时重新生成位图。
- 打开文档即在后台生成所有 Mermaid SVG 与正文尺寸的位图，不再等待图形滚入视口；源码模式也会准备图形缓存。
  正文行元素仍按视口创建，屏外图形已经完成解码，因此滚动时可直接显示。
- 100 ms 合并连续缩放 / 调整窗口尺寸；后台完成解码，过期请求不能替换当前结果。
- 每个预览实体只持有当前位图。直接将 `RenderImage` 交给 GPUI，绕过默认的全局资产缓存。
  替换分辨率、源码或主题，以及释放预览实体时，释放旧位图并清理 GPU 纹理。
- 正文继续保留每张图最大 4096 × 8192 像素、64 MiB 像素缓冲的保护。
  极端系统缩放可能达到该分辨率上限；不承诺任意窗口及系统缩放都具有无限像素清晰度。

独立查看窗口在创建时立即从 SVG 解码一张完整高清位图，固定目标为 SVG 逻辑宽高的 4 倍。
两条边均不超过 16384 像素，且总像素不超过 16,777,216；超限时保持宽高比例缩小。
GPUI 0.2.2 的 DirectX 与 Metal 图集源码均使用 16384 边长上限；正文的尺寸限制保持现有值。
每个查看窗口仅绘制这一张整图，保留完整 viewBox 与矢量几何。
缩放、拖动、松开、适合窗口、100%、窗口尺寸及系统 DPI 变化，只调整图像的显示尺寸和位置；
初次解码后不再调度任何补绘或替换分辨率，整图位图在关闭前保持同一实例。
打开时可能显示一次加载提示，加载完成后的查看操作不会重新进入加载状态。
固定像素规格意味着超大图或超出位图分辨率的放大会变模糊，适合窗口不改变位图分辨率。
64 MiB 是单个查看窗口的解码像素上限，不包含正文缓存、GPU 纹理及初次解码的临时分配。
关闭时释放整图位图、当前窗口的纹理并取消待处理任务；再次点击查看重新生成独立位图。

编辑器发出 `ViewDiagram` 事件，携带只读 SVG 快照；应用模块负责创建最大化的独立窗口。
查看窗口默认适合整张图，提供缩小、放大、100%、适合窗口；滚轮以鼠标位置为缩放中心，
鼠标左键拖动平移，Esc 或关闭快捷键只关闭查看窗口。手动缩放范围为 5%–800%。
Windows 查看窗口的关闭按钮直接绑定窗口关闭；系统关闭请求另有回调。
关闭按钮、系统关闭、Esc 与关闭快捷键均取消待处理解码、清空全部查看缓存，并移除当前窗口的 GPU 纹理。
已关闭实体不能再次发起渲染；正在执行的过期后台结果会丢弃。
查看内容是打开时的快照，修改正文后需要重新点击查看。打开和操作查看窗口不修改文档或撤销历史。

## 后续边界

本轮保留全部有效图形的正文分辨率缓存，不提供整份文档缓存预算。
正文打开后预先解码全部图形，因此内存随有效图形数量增长；查看整图位图独立于正文缓存，关闭查看窗口后释放。
大量图形、高 DPI 或正文手动放大后仍可能增加内存；进一步优化需要用户确认正文的总预算或淘汰方案。
