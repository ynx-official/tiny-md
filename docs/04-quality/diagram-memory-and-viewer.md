## 实现

- Mermaid 解析与布局结果生成具有逻辑尺寸的 SVG；流程图默认采用原生 ELK，其他类型与失败回退保留原有布局。
  不再预先放大宽高 3 倍；合法长图的逻辑边长保护调整为 128,000，正文和高清像素预算不变。
  当前布局、字体及编译优化见 [ELK 设计](../03-architecture/flowchart-elk-layout.md)，计时见 [加载性能](diagram-load-performance.md)。
- 正文按当前显示宽高乘窗口系统缩放决定像素尺寸；尺寸或 DPI 变化时先查缓存，未命中才解码。
- 打开文档时准备全部 Mermaid SVG 与正文尺寸位图；已缓存的结果直接复用，未命中的图后台生成，
  不再等待图形滚入视口；源码模式也会准备图形缓存。
  正文行元素仍按视口创建；屏外图形预生成完成后，滚动时可直接显示。
- 全部文档与独立查看窗口共享最多 5 个 CPU 计算名额，布局、正文位图及高清位图都计入同一上限。
  等待名额使用异步等待，不阻塞界面或占用后台线程。最多 5 个任务同时生成，第 6 个等待名额释放；
  命中缓存直接复用，不占计算名额。正在执行的同步计算即使被取消，也持有名额直到计算结束。
  队列只限制计算并发，不减少最终缓存数量，也不承诺总完成时间缩短。
- 请求在进入延时 / 异步调度前按源码顺序取得 FIFO 位置，布局与解码分别允许前 5 个请求推进，
  计算完成后按请求顺序发布到界面；每条队列最多保留 5 个尚未发布的结果，避免首图较慢时持续积压。
  同一 SVG 被文档中多个块复用时，后面的块仍等待前面的待处理块，不提前插入解码队列。
  取消任务移除对应排队位置；已开始的同步计算保留队列位置直到计算结束，过期结果丢弃。
- 尚无尺寸时按源码行数与方向估算骨架空间，沿用既有适宽 / 缩放规则；不是首次即可得知精确高度。
  相同源码的已有尺寸在主题重新加载时继续复用。真实布局完成后修正高度，保持当前顶部阅读行的屏幕位置，
  不再因流程图完成而拉回光标。显式文本编辑、源码切换或跳转继续遵循原有光标定位规则。
  位图生成只替换骨架，保留布局尺寸；骨架是静态节点与连接线，不调度动画。
- 正文滚动条通过共享拖动状态通知编辑器；按住滑块时冻结图形高度与错误源码的自动展开状态，
  松开后一次应用已知尺寸并保持阅读锚点。切换文档或窗口失活会清除冻结状态。
  首次估算可能与实际尺寸不同，正常加载或松开后滚动条长度可以修正；不把估算当作真实图形尺寸。
- 100 ms 合并连续缩放 / 调整窗口尺寸；后台完成解码，过期请求不能替换当前结果。
- 应用内共享缓存位于 `crates/editor-adapter/src/diagram_cache.rs`。SVG / 语法错误按完整源码和主题区分，
  正文位图按完整 SVG 与实际像素尺寸区分。渲染实现随当前进程固定，应用重启或升级后缓存重新建立。
  普通文字编辑保留图形；修改图源码只请求该图的新结果，撤销、主题往返或恢复窗口尺寸可命中旧结果。
  同一键的并发请求共用异步锁，取得锁后再次检查共享缓存，避免多个窗口同时未命中时重复计算。
  成功结果在等待按序显示之前写入缓存并释放键锁，后续相同请求可复用，也不会与显示顺序互相等待。
- SVG / 错误缓存默认 16 MiB，正文位图缓存默认 384 MiB，两者各最多 128 项。
  2026-10-14 修复第 23 张正常流程图的解析后，全篇 35 图在 200% DPI 下约 293 MiB；
  原 256 MiB 预算会在重开时淘汰首图，因此调整为 384 MiB。依据见 [解析兼容性](mermaid-parser-compatibility.md)。
  按最近使用顺序淘汰；SVG 预算计算源码和结果字节，位图预算计算像素缓冲与 SVG 键字节。
  使用共享引用复用同一位图，不为每个窗口复制像素缓冲。缓存只管理可复用结果，不强制卸载当前窗口正在使用的图。
- 当前流程图解码另外保留最多 64 MiB 的系统字体共享字节，避免逐字形反复映射字体文件。
  该数据跨图共享，只含系统字体且随进程退出释放；不扩大 SVG / 正文位图预算或单张像素上限。
  适配、读取失败回退与新旧位图一致性以 [ELK 设计](../03-architecture/flowchart-elk-layout.md) 和加载性能记录为准。
- 每个预览实体仍只持有当前位图，直接将 `RenderImage` 交给 GPUI，绕过默认的全局资产缓存。
  释放视图后正文 CPU 位图可在有界缓存中保留；最后一个使用者释放后清理 GPU 纹理，缓存淘汰后释放闲置像素。
  正在绘制的窗口会暂时离开 GPUI 窗口表，纹理清理延至 effect 结束并再次检查使用者，避免遗漏该窗口或误删其他窗口的图。
- 正文继续保留每张图最大 4096 × 8192 像素、64 MiB 像素缓冲的保护。
  极端系统缩放可能达到该分辨率上限；不承诺任意窗口及系统缩放都具有无限像素清晰度。

独立查看窗口在创建时立即提交一张完整高清位图的解码请求，等待共享计算名额后执行，固定目标为 SVG 逻辑宽高的 4 倍。
两条边均不超过 16384 像素，且总像素不超过 16,777,216；超限时保持宽高比例缩小。
GPUI 0.2.2 的 DirectX 与 Metal 图集源码均使用 16384 边长上限；正文的尺寸限制保持现有值。
每个查看窗口仅绘制这一张整图，保留完整 viewBox 与矢量几何。
缩放、拖动、松开、适合窗口、100%、窗口尺寸及系统 DPI 变化，只调整图像的显示尺寸和位置；
初次解码后不再调度任何补绘或替换分辨率，整图位图在关闭前保持同一实例。
打开时可能显示一次加载提示，加载完成后的查看操作不会重新进入加载状态。
固定像素规格意味着超大图或超出位图分辨率的放大会变模糊，适合窗口不改变位图分辨率。
64 MiB 是单个查看窗口的解码像素上限，不包含正文缓存、GPU 纹理及初次解码的临时分配。
关闭时释放整图位图、当前窗口的纹理并取消待处理任务；再次点击查看重新生成独立位图。

编辑器发出 `ViewDiagram` 事件，携带只读 SVG 快照；应用模块负责创建最大化的独立窗口。
查看窗口默认适合整张图，提供缩小、放大、100%、适合窗口；滚轮以鼠标位置为缩放中心，
鼠标左键拖动平移，Esc 或关闭快捷键只关闭查看窗口。手动缩放范围为 5%–800%。
Windows 查看窗口的关闭按钮直接绑定窗口关闭；系统关闭请求另有回调。
关闭按钮、系统关闭、Esc 与关闭快捷键均取消待处理解码、清空全部查看缓存，并移除当前窗口的 GPU 纹理。
已关闭实体不能再次发起渲染；正在执行的过期后台结果会丢弃。
查看内容是打开时的快照，修改正文后需要重新点击查看。打开和操作查看窗口不修改文档或撤销历史。

## 后续边界

本轮按用户选择使用应用会话内存缓存，不写入磁盘。应用重启、结果被淘汰或输入 / 像素尺寸变化后，必要时重新生成。
384 MiB 是当前共享正文缓存预算，不是进程总内存上限；正在使用的图形、高清查看、临时解码缓冲、GPU 纹理和元数据另计。
正文仍预生成全部图形，超出缓存预算的活动文档可继续持有其正在使用的图；大文档或多窗口的总占用仍随图数量增长。
独立查看窗口不读写正文位图缓存，关闭释放高清位图。此前“正文替换即释放旧 CPU 位图”的回归按本次明确缓存要求
调整为验证旧尺寸复用和淘汰后的释放；高清查看关闭释放回归保持原有断言。
