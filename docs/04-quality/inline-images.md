## 范围与使用

用户确认：在正文中显示 Markdown 图片，支持相对于当前 Markdown 文件的本地路径和 HTTP/HTTPS URL，Windows 与 macOS 共用实现。

```markdown
![方案阅读方式对比](../02-design/assets/p5-p6-plan-reading-comparison-v1.png)
![带空格的文件名](<../assets/方案 对比.png>)
![远程图片](https://example.com/image.png)
```

`![说明](地址)` 中的 `]` 和 `(` 必须相邻；`![说明]\(地址)` 是转义文本，不作为图片加载。
支持引用式图片、可选标题、中文路径、百分号编码、原生绝对路径及 `file:` URL。
相对路径以当前 `.md` 文件的父目录为基准，不使用程序工作目录。新建的未保存文档会提示先保存；
首次保存、另存为、打开及切换文件后更新基准目录。绝对路径仍遵循当前操作系统的文件规则。

支持 PNG、JPEG、GIF、WebP、BMP、ICO 和 SVG；动图显示首帧。图片按宽高比缩小到正文宽度，
小图不放大。独占一行的图片默认只显示预览，点击图片或把光标移到该行可编辑原始 Markdown；
预览仍保留在源码行下方。同行有正文或多张图片时，保留文字并按顺序在该行下方展示图片；
表格中的图片也展示在对应表格行下方。源码模式只显示原文，不发起新的图片加载。

代码块、行内代码、Front Matter 和已转义的图片语法不加载图片。2026-10-16 首次范围不包含 HTML `<img>`；
2026-10-27 用户确认扩展支持，尺寸、对齐和 HTML 表格单元格内显示规则见 [HTML 混排兼容](html-compatibility.md)。
图片拖放粘贴、图片编辑、独立放大查看仍不属于本次范围。SVG 不执行脚本，也不读取其内部引用的外部文件或嵌入附件。

## 实现与资源边界

- `crates/app` 向编辑器传递文档路径，覆盖初始化、文档安装及保存 / 外部同步。
- `markdown_images.rs` 使用现有 `markdown 1.0.0` 解析图片及引用定义，复用现有 `reqwest`、`image`、USVG / RESVG 依赖；图片元数据随正文解析缓存。
- `editor_images.rs` 管理异步任务与文档内位图；后台读取和解码，跨窗口最多同时执行 4 个普通图片加载任务。流程图原有调度不变。
- 同一文档中相同地址只加载一次。普通重绘、光标移动、缩放窗口及模式切换复用位图；修改地址、移除图片、切换路径及关闭文档释放旧位图和 GPU 纹理。无磁盘缓存。
- 旧请求结果带请求序号检查，不能覆盖新文档 / 新请求。任务取消后已开始的阻塞读取可能继续到完成或超时，但结果不再写回。
- 未完成或失败时预留 96 px 内容高度，上下各留 12 px；失败显示简短原因和“重试”。加载完成尽量保持当前阅读行位置，拖动滚动条时保持预留高度，松开后更新。
- 远程图片在排版模式自动请求 URL，不使用浏览器登录态，不自动保存下载文件。仅允许 HTTP/HTTPS；连接超时 10 秒、整次请求超时 20 秒，最多重定向 5 次。
- 单个文件最多 32 MiB，解码尺寸最多 16,777,216 像素且单边不超过 16,384 像素。超限、HTTP 错误、文件不存在或解码失败均显示错误，不修改 Markdown。
- 源码、撤销历史和文档脏状态不受图片加载、重试或阅读操作影响。加载和绘制共用跨平台代码，仅路径使用系统原生语义。

## 验证

首个 GPUI 回归在实现前实际失败：排版模式中图片没有预览或错误占位。
实现后图片专项测试覆盖语法、相对路径、中文 / 空格 / 编码、Windows 盘符 / UNC、真实 HTTP 服务器的重定向 / 404 / 无效内容、
解码限制与色彩通道、预览比例和宽度、点击编辑、源码切换、重复图片复用、缺失文件重试、另存为 / 文档切换及旧位图释放。
应用层测试另外通过真实保存流程核对路径传递。

GPUI 0.2.2 的调试元素查询保留旧帧的 selector，源码切换检查使用当前布局和原文高度，不把旧 selector 当作当前图片元素。
Windows 自动验证：236 项工作区测试、17 项发布工具测试、版本资料检查和格式检查通过。
原有 2 项流程图手工性能测试与 1 项 doctest 保持忽略。Clippy 首次指出测试服务器未处理部分读取，
改为完整读取请求头后，HTTP 回归与 `cargo clippy --locked --workspace --all-targets -- -D warnings` 均通过。
`cargo build --locked -p tiny-md` Windows 开发构建通过。
自动测试运行于 Windows 的 GPUI TestPlatform，不能代替 Windows / macOS 原生 GPU、系统交互和 macOS 编译验收。
