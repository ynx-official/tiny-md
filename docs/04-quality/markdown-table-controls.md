## 已确认范围

用户确认先实现 Markdown 管道表格的上下文工具栏与更多菜单，Windows / macOS 共用原生实现。
用户于 2026-10-28 后续要求补齐尺寸面板，替代此前延期安排，并确认仅在缩小范围内含内容时提示确认。
不包含单元格合并、矩形多选或 HTML 表格结构编辑。
沿用 `awesome-design-md` 的 `notion` 风格与项目既有原生字体、深浅色主题。

## 交互规则

- 光标位于表格单元格，或文本选区完全位于同一张表格内时显示工具栏；跨出表格的选区不提供表格操作。
- 左上角的左 / 中 / 右对齐作用于当前列，选中状态反映该列的对齐方式。
- 2026-10-28 用户要求增强 Markdown 表格的斑马纹：数据行从第二行起隔行使用浅灰底色，深色主题使用对应灰阶；按表格内行号交替，不随文档位置或滚动改变。保留独立表头底色，当前编辑行的高亮优先于斑马纹。只改变显示，不修改源码、行高或撤销历史。
- 用户随后反馈底纹仍不明显，并提供对照截图。采样确认参考表头与灰行为 `#F8F8F8`、白行为 `#FFFFFF`；因此将表头与隔行底纹改为不透明 `#F8F8F8`，替代此前半透明悬停色叠加的方案。深色主题对应使用 `#2C3035`，当前编辑行继续优先显示原有高亮。
- 右上角为更多菜单与整表删除。删除提示明确说明删除整张表格，可一次撤销。
- 可编辑表格上方固定保留 26 px 工具区；失焦隐藏按钮时不改变布局，不覆盖上方正文或表头。只读与源码模式不显示工具栏。
- 菜单含上下插入行、左右插入列、上下移动行、左右移动列、删除行列、复制表格、格式化表格源码和删除表格。
- 表头不能通过行操作删除或移动，表头上方插行置灰；可在表头下方插入数据行。数据行不能越过表头。
- 首末行列的越界移动、最后一列的删除置灰。允许删除最后一个数据行，保留表头与分隔行；整表删除走独立动作。
- 行列操作以光标（选区的活动端）所在单元格为目标，不把文本选区解释为矩形选区。
- 插入后定位新单元格，移动后跟随内容，删除后定位邻近单元格；移动列时列对齐随列移动。
- 复制返回该表格的原始 Markdown 文本，不包含相邻正文，不修改光标、选区、滚动或撤销历史。
- Shift+F10 打开更多菜单；上下键与 Tab / Shift+Tab 跳过禁用项，Home / End 跳到首末可用项，Enter 执行，Esc 关闭并恢复编辑焦点。
- 菜单在窗口边缘调整位置，低窗口内可滚动。工具栏随表格上沿滚动；表头滚出视口后仍可通过 Shift+F10 操作当前单元格。

## 表格尺寸

- 左上角网格按钮与更多菜单的“调整表格尺寸”打开同一个面板，显示当前“列 × 行”；行数包含表头，不包含 Markdown 分隔行。
- 面板提供 6 列 × 10 行的快捷网格，悬停只预览范围，点击应用；数字输入支持网格外的尺寸，点击“应用”或 Enter 才修改正文。
- 从右侧增减列、底部增减行，保留左上区域的内容与已有列对齐，新列默认左对齐。最少保留 1 列和 1 行表头，裁掉当前单元格时光标回到存留的邻近单元格。
- 将移除有内容单元格时显示数量和“确认缩小”，再次点击该按钮或 Enter 才执行。修改数字或重选网格会重新计算确认；空白范围直接缩小。
- Esc、取消或点击面板外关闭，保留原光标、选区和正文。Tab / Shift+Tab 在列数和行数输入框间切换并选中数值；输入框使用共享原生文本输入组件。
- 非整数、零和超限值显示原因且不能应用；实施上限为 128 列、2048 行及总计 65536 个单元格，用于限制一次性分配。已有超限表格不会因打开面板而修改。
- 尺寸不变时不重写源码、不增加历史；实际调整为一次撤销。行数单独调整或扩列保留隐藏的多余源码单元格，缩列时将它们计入内容移除提示。
- 弹层使用窗口边缘避让，低窗口内滚动；源码 / 只读模式或外部修改使目标失效时关闭。

## 源码与实现边界

`tables.rs` 负责上下文校验、行列与尺寸命令、内容移除计数和源码重组；`editor_tables.rs` 负责工具栏、弹出菜单和目标快照；`editor_table_size.rs` 保存尺寸草稿并渲染网格、输入和确认；`markdown_editor.rs` 接入布局、焦点与命令路径。
所有新增交互均位于共享编辑器适配层，没有 Windows / macOS 专用的表格行为分支，也没有新增依赖。

打开菜单时保留表格范围、原文、光标与选区。菜单占用键盘焦点期间保留原单元格的编辑布局；目标变化后关闭菜单，执行前再验证一次，避免外部文件刷新后使用旧目标。
打开、关闭、定位、复制不会重写源码。结构与对齐操作只重组当前表格，保留单元格内容和相邻正文；格式化命令额外补齐列间空格，重复执行不增加撤销项。
源码中超出表头列数的单元格继续保留，即便它们未参与预览。缺失单元格在结构修改时按空值补齐。

结构修改与整表删除各占一个撤销步骤；中文预编辑先沿用现有组合输入提交路径，与表格命令分开撤销。
HTML 表格中的管道文本也不提供 Markdown 表格工具，不把 HTML 表格转换成 Markdown。
源码模式保留既有顶部菜单命令入口；隐藏的是正文中的工具栏及其更多菜单。
