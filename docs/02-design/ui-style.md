用户随后提供 Typora Windows 截图，确认采用左侧应用图标与标题、顶部菜单、空白编辑区及底部视图按钮。
保留已有居中正文、默认隐藏排版工具栏与侧栏的写作布局，将风格应用于 Windows
标题栏、菜单、弹出层和基础控件。按用户后续的紧凑布局反馈，Windows 标题栏占 28 px，独立菜单行占 24 px，底栏占 28 px，
最小窗口宽度仍为 600 px；菜单行可横向滚动，文档标题截断以避免覆盖窗口按钮。
Windows 正文外层左右留白为 12 px、顶部留白为 16 px，保留编辑器内部 16 px 的左右留白；
文档最大宽度为 1080 px。后续布局反馈中进一步收紧了窄窗口边缘，并将标题上下留白缩至原来的 60%，
保留标题字级和正文、空行、代码、表格间距。macOS 保持原有留白。

浅色标题栏按用户截图使用浅蓝灰（`#f0f3f9`），顶部菜单保持白色。
其他浅色控件采用参考的白色画布（`#ffffff`）、暖灰表面（`#f6f5f4`）、细分隔线
（`#e5e3df`）、深色文字（`#37352f`）及浅灰悬停反馈。确认按钮与焦点环采用
参考的紫色主操作色（`#5645d4`），正文继续使用已有配色。

参考包含营销页组件，本应用保留实际写作流程，不增加营销页面、装饰卡片或品牌标志。
参考未给出完整深色主题，因此本轮继续使用既有编辑器深色配色，主题切换保留颜色对比度。

在线更新使用独立紧凑窗口，顶部为版本、自动检查偏好、状态和操作，日志区域独立滚动。
默认 680 × 610 px，最小 520 × 400 px；操作行可换行。Windows 使用 28 px 标题栏和明确的关闭按钮，
深浅色沿用上述画布、文字和边线。检查、下载、取消、失败重试和安装重启分别显示真实状态；
自动检查不占用正文区域。当前版本日志支持离线阅读，新版本日志取自发布正文。

Windows 使用参考字体回退中的 `Segoe UI`，代码使用系统自带的 `Consolas`；
macOS 保持既有系统字体及 `Menlo`。使用本机字体可避免依赖未安装的专有品牌字体。

macOS 继续使用系统顶部菜单，Windows 使用窗口内菜单，两者共用业务动作与文件保存保护。
窗口内菜单缓存属于各文档窗口，菜单勾选状态和最近文件变化时更新对应窗口的菜单定义。

Windows 菜单依次为文件(F)、编辑(E)、段落(P)、格式(O)、视图(V)、主题(T)、帮助(H)。
字母对应实际 Alt 访问键，悬停提示完整按键；F10 打开文件菜单。下拉操作的快捷键说明读取实际
键绑定，关闭菜单后恢复此前的编辑器或查找输入框焦点。视图菜单提供排版工具栏
开关，底栏常驻侧栏与源码模式入口。无文件路径启动时使用空白文档，帮助中的快速入门仍显示样例。
源码按钮根据状态显示“启用源代码模式”或“退出源代码模式”提示，并显示选中状态。
Windows 标题栏显示当前文档名，未保存的修改用 `•` 标记；保存或撤销到磁盘基准后清除标记。

流程图卡片增加“查看”文字按钮，独立查看窗口使用简洁画布、细分隔线和紧凑操作栏，
操作包括放大、缩小、100% 与适合窗口，底栏提示滚轮缩放、左键拖动和 Esc 关闭。
浅色延用白色画布、暖灰操作栏与深色文字；深色延用现有流程图主题。查看窗口显示打开时的只读快照。
点击查看时生成固定高分辨率整图，后续平移与缩放始终显示同一张位图；窗口中仅有一个图像层。
Windows 查看窗口使用明确绑定关闭动作的标题栏按钮；系统关闭、Esc 和关闭快捷键采用相同的高清资源释放规则。
实现与验证见 [流程图内存与独立查看](../04-quality/diagram-memory-and-viewer.md)。

按用户引用截图反馈，正文光标使用 1 px 的正文颜色细线（浅色 `#24292f`、深色 `#e4e6e9`），
每 500 ms 切换显隐；输入、移动与获得焦点时重新显示。中文组词期间保持可见，失焦或只读时隐藏。
引用块浅色文字为 `#787671`、竖线为 `#dde0e4`，深色使用 `#b2b7bf` 与 `#737b86`；
链接保留原有链接色。文件同步冲突在底栏显示简短提示及“处理同步冲突”入口，
完整规则见 [外部文件同步](external-file-sync.md)。
