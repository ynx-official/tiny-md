# 正文排版偏好

- 状态：Review

## 需求与截图依据

用户提供同一文档的 Tiny MD / Typora 截图，要求说明差异并做成偏好设置调节项。
截图中的 Tiny MD 正文约 1048 px，Typora 约 1140 px；字体字形、标题观感及块间留白也有差异。
截图不能证明 Typora 的具体字体、字号、主题配置或系统缩放值，不提供冒充精确复刻的预设。

实施选择：复用“文件 → 偏好设置”，新增“正文排版”分类，允许调整宽度、字体、字号、正文行高、段落间距。
这些是基于截图的实施取舍，不是用户逐项指定的数值。用户随后明确要求默认宽度改为 1140 px，
因此 Windows / macOS 均采用该默认值，恢复默认时也回到 1140；已保存的自定义宽度继续保留。
其他默认值沿用既有排版，用户可手动设为喜欢的密度。

## 控件与规则

| 选项 | 默认 | 范围及行为 |
|---|---|---|
| 正文宽度 | 1140 px（Windows / macOS 一致） | 480–2000 整数 px；指文字区域最大宽度，不包含编辑器左右内边距；窄窗口自动收窄 |
| 正文字体 | 系统默认 | 下拉搜索本机字体；字体不可用时由系统回退；菜单与其他工具窗口使用原字体 |
| 正文字号 | 16 px | 12–30 整数 px；标题按既有比例缩放，源码与代码继续使用等宽字体 |
| 正文行高 | 1.6 倍字号 | 1.2–2.4；用于正文、列表、引用和普通空行，标题与代码保留专用行高 |
| 段落间距 | 0.5 行 | 0.25–2；仅调整前后紧邻非空块的单个分隔空行；连续空行、文首文末及源码保留原规则 |

输入后按 Enter 或点击“保存并应用”，验证所有字段后一次保存并同步所有文档窗口。
“恢复默认”只重置本页排版选项。非法输入或写入失败显示错误，保留原已保存值与生效布局。
设置存入原 `preferences.json` 的 `typography` 字段，主题选择与排版互不覆盖；旧配置缺少该字段时使用默认值。
菜单缩放仍为当前窗口临时操作，“恢复实际大小”恢复所设正文字号；重新应用排版时所有文档统一到偏好字号。

调整排版只改变显示及输入几何，不改变源文、选区、组合输入、未保存状态或撤销栈。
字体、字号、宽度、行高与间距变化需要使相关布局缓存失效，光标与点击命中继续使用同一套行几何。
Windows / macOS 共用设置与渲染规则，保留平台标题留白的差异。

## 验收场景

- 旧主题配置读取默认排版；自定义值保存重启后恢复；主题切换和恢复排版默认值互不覆盖。
- 非法数字、范围外值与无法写入的路径不改变已保存配置或文档布局。
- 已打开及新建文档使用同一偏好；宽屏最大宽度正确，窄窗及侧栏开启后不溢出。
- 修改字号后缩放及恢复实际大小正确；切换主题不会丢失排版。
- 行高与段落间距变化后重新布局，点击、中文组合输入及撤销保持正确，源码模式保持等宽行高。
- 偏好设置最小尺寸 640 × 430 下内容可滚动、底栏可见，字体名称不挤出控件。
