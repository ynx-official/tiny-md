# 更新线路与测速

- 状态：Approved
- 最后更新：2026-10-28
- 关联文档：[偏好设置](preferences.md)、[更新架构](../03-architecture/online-updates.md)、[验证记录](../04-quality/update-routes.md)、[发布签名](../05-operations/update-signing.md)

## 确认与范围

用户于 2026-10-28 要求每次检查更新前检测 GitHub 和加速线路、支持手动检测并选择当前网络下响应最快的可用线路，随后确认页面效果图并要求实现。
沿用 Rust / GPUI 与 notion 原生适配；Windows / macOS 共用网络和设置逻辑。
本次扩展既有更新模块，保留稳定版通道、手动安装确认、未保存文档保护和开发构建禁止安装。

## 设置与状态

“偏好设置 → 更新”保留自动检查与后台下载，顶部显示编译版本，增加下载线路、手动测速、最近检测时间和线路列表。
默认窗口扩大为 900 × 700 px，最小 640 × 430 px；内容可滚动，底部“完成”固定，深浅色共用布局。

| 模式 | 规则 |
|---|---|
| 自动择优（默认） | 并行检测 GitHub、gh-proxy.com、ghfast.top，以及已保存的自定义线路 |
| 仅 GitHub | 检查、测速和下载不连接第三方代理 |
| 指定 gh-proxy.com / ghfast.top | 只通过选定线路下载，失败不擅自换到其他线路 |
| 自定义线路 | 保存 HTTPS 代理前缀后生效，可按 Enter 或“保存并使用” |

固定代理仍可能连接 GitHub 以核验历史无签名清单；界面明确说明这个兼容边界。
自定义地址不接受凭据、查询参数、片段、已拼接 GitHub URL 或本机 / 常见局域网 IP。
用户自行配置的域名仍需由用户信任，不将该输入验证宣称为 DNS 层隔离。

`update-settings.json` 新增 `route_mode` 与 `custom_route`；旧配置默认自动择优，保留频率、后台下载和最后检查时间。
设置先成功保存再应用，失败保留旧值。测速结果只在会话内保存，显示检测时间，重启后不把历史延迟当作当前值。
正在检查、下载或准备安装时锁定线路配置，避免切换配置改变在途任务。切换线路后清除上次版本与下载计划，下一次下载须重新检查。

## 探测与更新

1. 启动、定时和手动检查均先探测；“重新测速”仅更新线路状态，不下载、不打开更新窗口、不改最后检查时间。
2. 使用 HTTPS GET 请求本项目真实更新清单。每条线路最多连接 2 秒、整轮该线路请求预算 4 秒；并发执行，响应长度限制 2 MiB。
3. 列表显示清单完整接收与解析前后的请求耗时，包含 TLS / 重定向；它不是 ICMP ping、地理距离或大文件吞吐率。
4. 签名验证完成后，比较本轮可信响应里的最高稳定版本，较旧线路标记“版本落后”；同版本按响应耗时排序。可信来源对同版本附件不一致时拒绝选择。
5. 原 GitHub 清单 → API → 发布页回退继续保留。4 秒快速检测失败后仍可通过原接口获取可信元数据；该阶段不承诺整次检查 4 秒结束。回退成功可核验已经探测到的代理清单，不需要重复下载清单。
6. 每次检查重新探测，正式下载锁定已验证的版本、附件、大小和哈希。网络 / HTTP 可恢复错误才尝试本轮其他合格线路，每条最多一次；重新创建临时文件并从零下载。
7. 取消、磁盘错误、大小或哈希校验失败直接停止。下载中重测不切断或改变当前传输；等待下载时，仅同一版本和附件的重测结果可更新线路排序。

若没有可验证来源，反馈失败，不用未验证内容猜测版本。签名可以证明来源，不能证明代理没有返回旧的已签名版本；本轮最高可信版本与已安装版本比较也不等同于证明全球最新。

## 信任边界

HTTPS 验证始终开启；重定向只允许本次代理同源及现有 GitHub CDN 白名单，最多 6 次。逻辑附件地址仍限制为本仓库对应版本，代理只改变传输地址。
请求仅含公开更新资源，不附带 GitHub Token、文档或本地路径；设置中提示代理可见 IP 与请求文件。

新增 Ed25519 清单签名，客户端内置公钥，签名覆盖原始清单字节。SHA-256 继续验证安装包，新增 `notes_digest` 验证经代理获取的日志。
历史无签名清单必须与 GitHub 直连取得的版本和附件逐项一致，不能在直连失效时独立信任代理。
返回了签名但签名错误的线路直接排除，不降级成无签名清单。成功的另一条独立可信线路仍可使用。
全代理更新需要先发布带签名的新清单；首次密钥配置和发布步骤以[发布签名说明](../05-operations/update-signing.md)为准。

## 验收

- 自动检测、手动检测、线路状态、固定模式、自定义校验、旧配置兼容与保存失败保护。
- 原生窗口展示检测中与检测结果，更新窗口显示所用线路；最小尺寸可滚动访问操作，深浅色无重叠。
- 检测并发、错误 HTML、无签名断网、签名错误、旧缓存、元数据不一致与备用接口核验。
- 网络失败有界切换，取消 / 完整性错误不切换；每次下载锁定同一版本并继续进行原有安装前校验。

实际证据与未验收范围见[验证记录](../04-quality/update-routes.md)。
