# 表格验收

| 名称 | 描述 | 状态 |
| :--- | :---: | ---: |
| 中文 🌱 | **粗体**、*斜体*、`a\|b` | 100 |
| 👩‍💻 与 é | 长文本自动换行，窗口变窄后继续保持行高和单元格边界。 | 42 |
| 缺少单元格 |

点击单元格编辑；Tab 切换单元格，Enter 跳到下一行，末行会新增一行。

定位到表格后，左上角切换当前列对齐，右上角提供更多菜单和整表删除。
Shift+F10 打开表格菜单；上下键 / Tab 选择可用操作，Enter 执行，Esc 返回编辑。
检查移动行列、复制、格式化、删除与撤销；打开菜单和复制不得修改正文。
点击左上角网格按钮：悬停预览不改正文，点击网格应用；数字输入列数和行数（含表头），Enter 应用。
检查增加空白行列后可一次撤销；缩小有内容范围先提示移除数量，取消应保留内容，确认后可一次撤销。
检查空白范围直接缩小、无效数字不能应用、Tab 切换数值、Esc 返回原单元格，低窗口中面板可滚动。
