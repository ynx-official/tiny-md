# 代码与流程图

## 代码块

```rust
fn main() {
    let message = "你好，tiny-md！";
    println!("{message}");
}
```

## 流程图

```mermaid
flowchart LR
    A[开始] --> B{保存？}
    B -->|是| C[完成]
    B -->|否| D[继续编辑]
```

点击流程图编辑，再点击这里恢复预览。

## 长流程图：适宽、缩放与滚动

```mermaid
flowchart TD
    P0[创建项目与智能分流] --> P1[定义项目价值与边界]
    P1 --> P2[共创客户、场景与问题]
    P2 --> P3[共创方案与价值主张]
    P3 --> P4[构建精益画布与商业闭环]
    P4 --> P5[设计 MVP 与关键假设实验]
    P5 --> P6[规划业务动作、里程碑与验收]
    P6 --> P7[匹配操盘手、资源、财务与风险]
    P7 --> P8[AI 审计与专家共创]
    P8 --> P9[立项评审与分段决策]
    P9 -->|调整| P1
    P9 -->|探索| P5
    P9 -->|暂缓| H[等待重启条件]
    P9 -->|通过| P10[证据执行：0→1→复制→扩张]
    P10 --> G{下一 Gate 是否通过}
    G -->|通过| P10
    G -->|调整| P1
    G -->|终止| E[关闭并沉淀学习]
    P9 -->|不通过| E
```

长图保持文字可读，预览区域随图形高度自动展开，滚动正文查看后续节点。上方按钮可调整缩放并恢复适宽。
