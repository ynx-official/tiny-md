## 功能特性

🔌 **TCP / UDP 转发**，在界面中连接、断开，断线后自动重连

📥 **导入已有配置**，支持 Java 客户端 YAML，预览确认后保存

🧭 **原生系统托盘**，关闭窗口后继续运行，随时恢复主窗口

🚀 **启动设置**，按需开启开机自启和启动后自动连接

📋 **连接日志**，支持搜索、筛选、暂停查看和导出

🔐 **凭证保护**，License 与证书口令保存在系统安全存储中
